# 🧮 Calculator

A simple and responsive Calculator built using **HTML**, **CSS**, and **JavaScript**. This project performs basic arithmetic operations with an attractive user interface and a responsive design.

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear Display
- 📱 Responsive Design
- 🎨 Modern UI with Background Image
- ⚡ Fast and Easy to Use

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/HariHaran8080/Calculator.git
```

2. Navigate to the project directory

```bash
cd Calculator
```

3. Open `index.html` in your browser.

No additional installations are required.
